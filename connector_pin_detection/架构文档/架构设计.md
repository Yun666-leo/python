# 架构设计文档

## 整体架构

采用分层模块化架构，各模块职责清晰、可独立测试。

### 数据流

```
摄像机 → 拍照/文件夹监听 → 图像预处理 → ROI提取 → 引脚检测 → 间距测量 → 缺陷判定 → 结果输出
```

### 模块说明

| 模块 | 职责 | 关键技术 |
|------|------|----------|
| image_processing | 去噪、增强、二值化、形态学清洗 | CLAHE, 自适应阈值, 中值/高斯滤波 |
| pin_detection | 引脚定位与筛选 | 轮廓分析, 几何特征筛选, 最小外接矩形 |
| measurement | 间距计算与相机标定 | 欧氏距离, 像素-物理尺寸转换 |
| classification | 缺陷判定 | 公差比较, 统计分析和逐间距判定 |
| camera | 摄像机管理 | USB/RTSP/FILE三种模式, 实时预览, 参数调节 |
| watcher | 文件夹热监听 | 自动扫描新文件, 触发检测回调 |
| gui | 可视化界面 | Tkinter, 图像显示, 实时预览, 摄像头控制 |

### 摄像机接入方式

1. **USB摄像头** — 即插即用，通过 `device_index` 指定
2. **RTSP网络摄像机** — 通过 RTSP URL 接入，支持工业IP相机
3. **文件夹监听** — 外部相机拍照保存到目录后自动触发检测

### 工业场景优化策略

1. 光照不均 → CLAHE + 自适应阈值
2. 引脚密集 → 形态学开闭运算分离粘连
3. 摆放偏移 → 自动ROI提取 + 方向校正
4. 微小尺寸 → 亚像素精度的轮廓分析
5. 实时性 → 纯OpenCV实现，规避深度学习推理延迟
